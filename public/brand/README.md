# Brand Kit — CCNetball + Coach Caitlyn

Two complementary brand identities sharing the same colour palette and
typography:

- **CCNetball** — the website / business brand (`ccnetball.com`)
- **Coach Caitlyn** — Caitlyn's personal coaching brand (social, business
  cards, signage)

Both use the same **CC** mark — convenient because both brand names share
the same initials. Use whichever suits the medium: business-side
collateral leans **CCNetball**, personal-facing collateral (her socials,
business cards, name badge, banner at courts) leans **Coach Caitlyn**.

All files are SVG (vector). They scale to any size with zero quality
loss and can be converted to PNG / JPG / PDF in any design tool (Canva,
Figma, Illustrator) or by right-clicking the file in your browser and
saving as PNG.

## Brand colours (hex codes)

| Name | Hex | RGB | Use |
|------|-----|-----|-----|
| **Raspberry** | `#E63B7A` | `230, 59, 122` | Primary brand colour. Buttons, highlights, the "CC" mark, "Caitlyn" wordmark accent. |
| **Raspberry Dark** | `#B82A60` | `184, 42, 96` | Hover states, secondary accents, deeper gradient stops. |
| **Coral** | `#FFB4A2` | `255, 180, 162` | Soft accents, gradient finishers, light highlights, white-version logo accent. |
| **Navy** | `#1A1F36` | `26, 31, 54` | Body text, dark backgrounds, "Coach" wordmark, secondary brand colour. |
| **Cream** | `#FDFAF7` | `253, 250, 247` | Page backgrounds. Warm, fresh, premium. |
| **Cream Warm** | `#F8F2EA` | `248, 242, 234` | Subtle section backgrounds, muted cards. |

**Gradient (raspberry → coral)** used on the CC mark and the "Caitlyn"
wordmark:

```
linear-gradient(135deg, #E63B7A 0%, #FF6B9D 60%, #FFB4A2 100%)
```

The lighter `#FF6B9D` mid-stop is part of the gradient and lifts it
toward coral — it is not a standalone brand colour, just the visual
bridge between Raspberry and Coral.

## Typography

- **Display (headings, logo, big titles):** Plus Jakarta Sans — weights 700 / 800
- **Body (paragraphs, captions):** Inter — weights 400 / 500 / 600

Both are free Google Fonts. If you can't access them in print software,
fall back stack: Helvetica Neue → Arial → system-ui.

## Logo usage rules

**Do:**
- Give the logo room. Keep at least the height of the "C" as clear space on every side.
- Use the colour version on cream / white backgrounds.
- Use the white version on photos and dark backgrounds.
- Use **Coach Caitlyn** on personal-facing collateral, **CCNetball** on business / website.

**Don't:**
- Stretch, skew, or rotate the logo.
- Recolour the gradient. Either use the gradient version or the white/navy mono versions.
- Place the colour logo on busy photos — use the white version.
- Mix the two brands inside the same composition (e.g. don't put both wordmarks side by side).

## Need a PNG?

1. Open the SVG file in any modern browser (Chrome, Safari).
2. Right-click → **Save Image As** → choose `.png`. Done.
3. Or upload the SVG to **canva.com** or **figma.com** and export as PNG / JPG.

For business cards or print, the SVG can go straight into the print
file. Most printers accept SVG, PDF, or 300 DPI PNG. SVG is best — it
will print sharp at any size.
