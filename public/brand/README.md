# CCNetball Brand Kit

Everything you need to put the CCNetball brand on anything: business cards,
social media, posters, email signatures, sponsor decks, you name it.

All files are SVG (vector). They scale to any size with zero quality loss
and can be converted to PNG/JPG/PDF in any design tool (Canva, Figma,
Illustrator) or by right-clicking the file in your browser and saving as
PNG.

## Files

| File | Use it for |
|------|-----------|
| `logo-mark.svg` | The CC mark on raspberry. Profile pictures, app icons, watermarks. |
| `logo-mark-white.svg` | Outlined CC for placing on photographs or coloured backgrounds. |
| `logo-mark-navy.svg` | CC mark on navy. Use when raspberry would clash. |
| `logo-full.svg` | Full horizontal logo (mark + wordmark). Default for everything. |
| `logo-full-white.svg` | Full logo for dark backgrounds. |
| `logo-stacked.svg` | Vertical lockup with tagline. Posters, large print, sponsor banners. |
| `logo-wordmark.svg` | Text-only "CCNetball". Tight horizontal spaces, email signatures. |
| `avatar-1024.svg` | Square 1024×1024 social profile picture (Instagram, Facebook, LinkedIn). |
| `og-image.svg` | 1200×630 link preview image. Used automatically when ccnetball.com is shared. |
| `favicon.svg` | Tiny rounded square mark for browser tabs and favicons. |
| `palette.svg` | Visual reference of all brand colours with hex codes. |

## Brand colours

| Name | Hex | Use |
|------|-----|-----|
| Raspberry | `#E63B7A` | Primary brand colour. Buttons, highlights, "CC" mark. |
| Raspberry Dark | `#B82A60` | Hover states, secondary accents. |
| Coral | `#FFB4A2` | Soft accents, gradient finishers, light highlights. |
| Navy | `#1A1F36` | Body text, dark backgrounds, secondary brand colour. |
| Cream | `#FDFAF7` | Page backgrounds. Warm, fresh, premium. |
| Cream Warm | `#F8F2EA` | Subtle section backgrounds, muted cards. |

## Typography

- **Display (headings):** Plus Jakarta Sans — weights 700 / 800
- **Body (paragraphs):** Inter — weights 400 / 500 / 600

Both are free Google Fonts. If you can't access them, fall back to
Helvetica Neue, Arial, or system-ui.

## Logo usage rules

**Do:**
- Give the logo room. Keep at least the height of the "C" as clear space.
- Use the colour version on cream/white backgrounds.
- Use the white version on photos and dark backgrounds.

**Don't:**
- Stretch or skew the logo.
- Recolour the gradient. Either use the gradient version or the white/navy mono version.
- Place the colour logo on busy photos. Use the white version.

## Quick "I need a PNG" guide

1. Open the SVG file in any modern browser (Chrome, Safari).
2. Right-click → Save Image As → PNG. Done.
3. Or upload the SVG to **canva.com** or **figma.com** and export as PNG/JPG.
